About CyberTrace


CyberTrace is an academic suspicious log analyzer built in C++ to demonstrate Design and Analysis of Algorithms in log processing.

Algorithms demonstrated:
Hashing · Sorting · Linear Search · Binary Search · Rabin-Karp

This interface displays data from the project's simulated log file. It is an academic demonstration and not a live threat detection system.
